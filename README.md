# cheenabisht.github.io

Personal portfolio website for **Cheena Bisht** — B.Tech CSE student specializing in AI/ML at Shri Ramswaroop Memorial University, Lucknow.

## Tech Stack

- **React** + **Vite** — fast build tooling
- **Tailwind CSS** — utility-first styling
- **Motion for React** — scroll-triggered animations
- **Lucide** — icon system

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Deployment

Automated via GitHub Actions. Push to `main` to deploy to GitHub Pages.

## Customization

All content is centralized in [`src/data/content.js`](src/data/content.js).

### Placeholders to Update

- **Portrait photo:** Replace the placeholder in `Hero.jsx` with an `<img>` tag
- **Email:** Update `siteConfig.email` in `content.js`
- **LinkedIn:** Update `siteConfig.linkedin` in `content.js`
- **Projects:** Add verified projects to the `projects` array in `content.js`
